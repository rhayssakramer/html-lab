01 · HISTÓRIA DO HTML

A jornada do HTML através dos tempos.

Criada por Tim Berners-Lee e publicada na década de 1990, o HTML (HyperText Markup Language) é a linguagem padrão para criação de páginas na web. Sua história remonta ao início da internet moderna e passou por diversas evoluções ao longo dos anos. É hoje a linguagem base para todos os sites na Internet.

📅 Origens e Primeiras Versões (1989 - 1995)

  • Em 1989, Tim Berners-Lee, cientista do CERN, propôs um sistema de hipertexto para facilitar o compartilhamento de informações entre pesquisadores.
  • Em 1991, ele criou a primeira versão do HTML, com 18 tags básicas, incluindo <p>, <a>, <h1>, <title>, <body> e <img>.
  • Em 1993, a primeira especificação formal do HTML foi publicada por Berners-Lee e o NCSA Mosaic popularizou a web.
  • Em 1995, surgiu o HTML 2.0, consolidando os padrões usados na época.

📈 Evolução e Padrões (1997 - 2004)

  • HTML 3.2 (1997): Introduziu suporte a tabelas, scripts e estilização via CSS.
  • HTML 4.01 (1999): Separou estrutura (HTML) da apresentação (CSS), tornando o código mais limpo.
  • XHTML (2000 - 2004): Tentou tornar o HTML mais rígido e baseado em XML, mas não foi amplamente adotado.

🚀 O Surgimento do HTML5 (2008 - Presente)

  • Em 2008, o HTML5 foi proposto pelo WHATWG e W3C, focando em interatividade e suporte a multimídia sem plugins como Flash.
  • O HTML5 foi oficializado em 2014, trazendo novidades como:
    • 🏷️ Tags semânticas (<header>, <article>, <section>, <footer>).
    • 🎬 Elementos multimídia nativos (<video>, <audio>).
    • 🎨 Canvas e SVG para gráficos dinâmicos.
    • ⚙️ APIs para geolocalização, armazenamento local e aplicações offline.

03 · O QUE É HTML?

A linguagem de marcação que constrói a web.

É uma linguagem de marcação utilizada na construção de páginas web/websites, no desktop ou mobile. HTML quer dizer "Hyper Text Markup Language" ou seja "Linguagem de Marcação de Hipertexto". O HTML é a base para todas as aplicações web que visualizamos.

⚠️ Atenção! HTML não é linguagem de programação. HTML baseia-se em marcações que dão significado aos elementos.

🏷️ Tags e Estrutura

O HTML baseia-se em Tags para definir o seu conteúdo. As Tags são delimitadas pelos sinais de < e > e definem o significado de um determinado elemento.

<p> Um parágrafo </p>
📌 Exemplo: Para definir um parágrafo no documento na página web, utiliza-se a tag p entre o sinal de maior e menor <p> e um texto. Tem-se ainda a tag de abertura <> e a tag de fechamento </>, que delimitam o conteúdo desse parágrafo.

🌐 O Papel do HTML

O HTML conta ainda com diversas outras tags que estruturam o documento, adicionando imagens, cabeçalhos, botões, elementos de interação com o usuário, como campos para digitação de texto, que poderão ser interpretados e apresentados para o usuário de forma amigável.

Um documento HTML é composto por diversas tags que em conjunto, definem a estrutura e o conteúdo da página, e também como ela deve ser lida, tanto por um ser humano, como por uma máquina que irá interpretar aquele documento, que é normalmente, um navegador da internet.

📌 Navegadores: Os browsers são software capazes de interpretar um documento HTML e gerar um resultado gráfico. E esse resultado é aquele que vemos quando abrimos um site no nosso navegador.

🎨 HTML + CSS + JavaScript

O HTML é responsável pela estrutura e na aparência visual contam como CSS "Cascading Style Sheets" e o JavaScript, duas outras linguagens empregadas na programação web, em conjunto com o HTML, para definir a aparência e o funcionamento das páginas.

💡 Dica: A documentação do HTML está no site w3schools.com.
04 · FERRAMENTAS PARA COMEÇAR

Tudo que você precisa já está no seu computador.

Para escrever HTML você só precisa de duas coisas: um editor de texto e um navegador. Nada de instalar compiladores ou servidores para começar.

📝 Editor de código

VS Code (recomendado, gratuito), Sublime Text, Notepad++ ou até o Bloco de Notas. Editores de código colorem a sintaxe e completam as tags para você.

🌐 Navegador

Chrome, Edge, Firefox ou Safari. Basta dar duplo clique no arquivo .html para abri-lo.

🔍 DevTools

Ferramentas de desenvolvedor do navegador. Abra com F12 ou Ctrl+Shift+I (Cmd+Option+I no Mac).

🧩 Extensões úteis (VS Code)

Live Server (recarrega a página ao salvar), Prettier (formata o código) e Auto Rename Tag (renomeia a tag de fechamento junto).

📁 Regras dos arquivos HTML

  • A extensão é .html (ou .htm, mais antiga)
  • A página principal de um site se chama index.html: servidores a abrem automaticamente ao acessar uma pasta
  • Use nomes sem espaços, sem acentos e em minúsculas: sobre-nos.html, não Sobre Nós.html
  • Salve sempre com codificação UTF-8 (padrão no VS Code)
✨ Hack do VS Code: em um arquivo .html vazio, digite ! e pressione Tab. O Emmet gera toda a estrutura básica do documento! Experimente também ul>li*3 + Tab.
05 · ESTRUTURA BÁSICA DE UM DOCUMENTO

O esqueleto de toda página web.

Todo documento HTML segue a mesma estrutura mínima. Memorize este modelo: ele é o ponto de partida de qualquer página.

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Meu primeiro parágrafo.</p>
  </body>
</html>

🔎 Linha por linha

CódigoO que faz
<!DOCTYPE html>Declara que o documento é HTML5. Não é uma tag, é uma instrução para o navegador usar o modo padrão de renderização.
<html lang="pt-BR">Elemento raiz: envolve todo o documento. O lang informa o idioma para leitores de tela, tradutores e buscadores.
<head>Cabeça: informações sobre a página (metadados). Nada aqui aparece no corpo da página.
<meta charset="UTF-8">Codificação de caracteres. Garante que acentos e emojis apareçam corretamente (sem "Ã§Ã£o").
<meta name="viewport">Faz a página se adaptar à largura do celular. Sem ele, o site aparece "miniaturizado".
<title>Texto da aba do navegador, dos favoritos e do título no Google. Obrigatório!
<body>Corpo: todo o conteúdo visível (textos, imagens, links, botões).

🌳 Hierarquia: pais, filhos e irmãos

O HTML é uma árvore. Cada elemento dentro de outro é seu filho; elementos lado a lado são irmãos.

html                  ← raiz (pai de head e body)
├── head              ← filho de html, irmão de body
│   ├── meta
│   ├── meta
│   └── title
└── body              ← filho de html
    ├── h1            ← filho de body, irmão de p
    └── p
⚠️ Regra: só pode existir um <html>, um <head> e um <body> por documento, e o <head> sempre vem antes do <body>.

Desmontando um elemento peça por peça.

Tag e elemento não são a mesma coisa! A tag é a marcação (<p>); o elemento é o conjunto completo: tag de abertura + conteúdo + tag de fechamento.

07 · ELEMENTOS: ANINHAMENTO, VOID E BLOCK × INLINE

Como os elementos se encaixam.

🪆 Aninhamento (nesting)

Elementos podem ficar dentro de outros, como bonecas russas. A regra de ouro: o último a abrir é o primeiro a fechar.

✅ Correto

<p>Isso é <strong>muito
<em>importante</em></strong>!</p>

❌ Errado (tags cruzadas)

<p>Isso é <strong>muito
<em>importante</strong></em>!</p>

🕳️ Elementos vazios (void)

Alguns elementos não têm conteúdo, então não têm tag de fechamento:

<br>  <hr>  <img>  <input>  <meta>  <link>
<area>  <base>  <col>  <embed>  <source>  <track>  <wbr>
📌 E o <br />? A barra no final vem do XHTML. Em HTML5 ela é opcional e ignorada: <br> e <br /> são idênticos. Mas <div /> não fecha a div!

🧱 Block × Inline

Por padrão, cada elemento tem um comportamento de exibição:

Block (bloco)

  • Começa em uma nova linha
  • Ocupa toda a largura disponível
  • div, p, h1–h6, ul, section, form, table

Inline (em linha)

  • Fica na mesma linha do texto
  • Ocupa só o espaço do conteúdo
  • span, a, strong, em, img, code, button

👀 Resultado Visual:

<div> bloco

<p> bloco com <span> inline e <a> inline no meio do texto, <strong> também.

<h4> bloco

✨ Tags de fechamento opcionais: a especificação permite omitir </p>, </li>, </td>, </tr>, </option> e até <html>, <head> e <body>! O navegador cria tudo sozinho. Funciona, mas sempre feche: fica mais legível e evita surpresas.
08 · ATRIBUTOS

Configurando os elementos com atributos.

Atributos dão informações extras a um elemento: para onde um link aponta, qual imagem carregar, o idioma de um texto, etc.

<img src="gato.jpg" alt="Gato dormindo" width="300">
<a href="contato.html" title="Fale conosco">Contato</a>

📏 Regras de escrita

  • Sempre na tag de abertura
  • Formato nome="valor", separados por espaço
  • Use aspas duplas (padrão); aspas simples também funcionam
  • Nomes de atributos não diferenciam maiúsculas/minúsculas, mas use minúsculas
  • Não repita o mesmo atributo na mesma tag (só o primeiro vale)

✅ Atributos booleanos

Alguns atributos funcionam apenas por estarem presentes, sem valor:

<input type="checkbox" checked>
<button disabled>Indisponível</button>
<video src="aula.mp4" controls autoplay muted loop></video>
⚠️ Pegadinha: disabled="false" continua desabilitado! Para booleanos, o que importa é a presença do atributo. Para "desligar", remova-o.

09 · TAGS PRINCIPAIS

As tags que você vai usar todo dia.

O HTML tem mais de 100 elementos, mas um grupo pequeno resolve a maior parte das páginas. Cada um será aprofundado nas próximas aulas.

📰 Títulos e textos

<h1> a <h6> títulos, <p> parágrafo, <strong> importância, <em> ênfase, <br> quebra de linha, <hr> divisão temática, <blockquote> citação, <code> código. (Aula 2)

🔗 Links

<a href="..."> para outras páginas, seções (#id), e-mail (mailto:) e telefone (tel:). (Aula 3)

🖼️ Mídia

<img>, <figure>, <picture>, <video>, <audio>, <iframe>, <svg>, <canvas>. (Aulas 4 e 7)

📝 Formulários

<form>, <input>, <label>, <textarea>, <select>, <button>. (Aula 5)

📋 Listas

<ul> não ordenada, <ol> ordenada, <li> item, <dl>/<dt>/<dd> definições. (Aula 6)

📊 Tabelas

<table>, <thead>, <tbody>, <tr> linha, <th> cabeçalho, <td> célula, <caption> legenda.

🏛️ Estrutura semântica

<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>. (Aula 8)

📦 Genéricas

<div> (bloco) e <span> (inline): caixas sem significado, usadas para agrupar e estilizar quando nenhuma outra tag serve.

🧪 Exemplo com as tags principais

<h1>Receita de Bolo</h1>
<p>Um bolo <strong>fácil</strong> e <em>delicioso</em>.</p>
<img src="bolo.jpg" alt="Bolo de chocolate fatiado" width="300">

<h2>Ingredientes</h2>
<ul>
  <li>2 ovos</li>
  <li>1 xícara de açúcar</li>
</ul>

<p>Veja mais em <a href="https://exemplo.com">nosso site</a>.</p>
10 · O <HEAD> EM DETALHE

O que fica escondido no topo da página.

O <head> não aparece na tela, mas controla como a página é carregada, exibida, compartilhada e encontrada no Google.

<head>
  <!-- Essenciais -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bolo de Chocolate | Receitas da Vó</title>

  <!-- SEO -->
  <meta name="description" content="Receita de bolo fofinho em 30 minutos.">
  <link rel="canonical" href="https://receitas.com/bolo">

  <!-- Ícones e cor do navegador mobile -->
  <link rel="icon" href="favicon.ico">
  <link rel="apple-touch-icon" href="icone-180.png">
  <meta name="theme-color" content="#ff6b35">

  <!-- Compartilhamento (WhatsApp, LinkedIn, Facebook) -->
  <meta property="og:title" content="Bolo de Chocolate">
  <meta property="og:description" content="Fofinho e fácil!">
  <meta property="og:image" content="https://receitas.com/bolo.jpg">

  <!-- CSS e JavaScript -->
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>

📋 Elementos permitidos no head

ElementoUso
<title>Título da aba (obrigatório, único)
<meta>Metadados: charset, viewport, description, robots, theme-color, Open Graph
<link>Recursos externos: CSS, favicon, fontes, canonical, preload
<style>CSS escrito no próprio documento
<script>JavaScript (de preferência com defer)
<base>URL base para todos os links relativos da página
<noscript>Conteúdo alternativo se o JavaScript estiver desativado

⚡ Dicas de performance no head

<!-- Conecta antecipadamente a um domínio externo -->
<link rel="preconnect" href="https://fonts.googleapis.com">

<!-- Baixa com prioridade um recurso que será usado logo -->
<link rel="preload" href="hero.webp" as="image">

<!-- Baixa em segundo plano a provável próxima página -->
<link rel="prefetch" href="aula2/index.html">
✨ Dica: o <meta charset> deve estar nos primeiros 1024 bytes do documento, por isso ele é sempre a primeira linha do head.

            12 · SEMÂNTICA E ACESSIBILIDADE
            
HTML descreve o significado, não a aparência.


            

                
Semântica é usar cada tag pelo que ela significa. Um <h1> não serve para "deixar o texto grande"; serve para dizer "este é o título principal". O tamanho é trabalho do CSS.


                

                    

                        
❌ Sem semântica ("div-sopa")

                        
<div class="topo">
  <div class="titulo">Meu Blog</div>
</div>
<div class="post">
  <div class="negrito">Olá!</div>
  <div onclick="ir()">Ler mais</div>
</div>

                    

                    

                        
✅ Semântico

                        
<header>
  <h1>Meu Blog</h1>
</header>
<article>
  <h2>Olá!</h2>
  <a href="post.html">Ler mais</a>
</article>

                    

                


                
🏆 Por que a semântica importa?

                
    
                    
  • Acessibilidade: leitores de tela anunciam "título nível 1", "link", "navegação", e permitem pular direto para eles
    • 
                    
  • SEO: o Google entende melhor a hierarquia e o assunto da página
    • 
                    
  • Funcionalidade grátis: <button> e <a> já funcionam com teclado (Tab, Enter); uma <div> não
    • 
                    
  • Manutenção: o código fica autoexplicativo para outras pessoas (e para você no futuro)
    • 
                    
  • Modo leitura: navegadores e apps conseguem extrair o conteúdo principal
    • 
                


                

                    📌 Regra prática: antes de usar <div> ou <span>, pergunte: "existe uma tag que descreve isso?". Se existir, use-a. A Aula 8 é inteira sobre HTML semântico!
                

                

                    ⚠️ Títulos: use um <h1> por página e não pule níveis (h1 → h2 → h3). Escolha o nível pela hierarquia, nunca pelo tamanho da fonte.

            14 · COMUNICAÇÃO CLIENT X SERVER
            
Cliente e servidor: duas partes que conversam.

            
            

                
O modelo Client x Server (Cliente x Servidor) é um dos fundamentos da computação em redes e do desenvolvimento web. Ele define como os dispositivos se comunicam na internet ou em sistemas distribuídos.


                
🔄 O Modelo

                
O modelo Cliente-Servidor divide a comunicação entre dois papéis principais:


                

                    

                        
👤 Cliente (Front-end)

                        
    
                            
  • Solicita informações ou serviços
    • 
                            
  • Pode ser um navegador, aplicativo mobile ou qualquer dispositivo que consome dados
    • 
                            
  • Quando você acessa um site, seu navegador é o cliente
    • 
                        

                    

                    

                        
🖥️ Servidor (Back-end)

                        
    
                            
  • Processa as solicitações do cliente e responde com dados necessários
    • 
                            
  • Pode hospedar bancos de dados, APIs ou arquivos
    • 
                            
  • Quando você acessa um site, o servidor do site retorna a página
    • 
                        

                    

                


                
📡 Fluxo de Comunicação

                
    
                    
  1. O cliente envia uma requisição para o servidor (exemplo: "Quero acessar a página X").
    2. 
                    
  2. O servidor processa essa requisição, busca as informações necessárias e responde.
    3. 
                    
  3. O cliente recebe os dados e exibe para o usuário.
    4. 
                


                
Cliente → (HTTP) → Servidor
Cliente ← (HTTP) ← Servidor


                
🔗 Tipos de Comunicação Cliente-Servidor

                
    
                    
  • Requisições HTTP/HTTPS: Comunicação tradicional baseada em requisições e respostas.
    • 
                    
  • WebSockets: Comunicação em tempo real bidirecional.
    • 
                    
  • APIs REST ou GraphQL: Formas estruturadas de envio e recebimento de dados.
    • 
                


                

                    📌 Exemplo do dia a dia:
                    
    
                        
  • Você digita www.google.com no navegador

            15 · O QUE SÃO PROTOCOLOS?
            
As regras que fazem a comunicação funcionar.

            
            

                
Protocolos são regras de comunicação. Na computação, um protocolo define como dois sistemas se comunicam, ou seja:

                
    
                    
  • Como a mensagem é enviada
    • 
                    
  • Como ela deve ser recebida
    • 
                    
  • Em que formato
    • 
                    
  • Em que ordem
    • 
                    
  • O que fazer em caso de erro
    • 
                


                

                    💡 Analogia simples (vida real): Imagine uma conversa no WhatsApp: Idioma = Português, Estrutura = pergunta → resposta, Emojis, áudios, textos têm regras. Se alguém falasse japonês do nada, a conversa quebraria. 👉🏼 Protocolos são o "idioma" que computadores usam para conversar.
                


                
🔌 Principais Protocolos

                
    
                    
  • HTTP (HyperText Transfer Protocol)
                        
      
                            
    • Protocolo da web
      • 
                            
    • Usado em sites, APIs, sistemas web
      • 
                            
    • Exemplo: GET /usuarios

    •

      • 
                            
    • Protege: Senhas, dados pessoais, informações bancárias
      • 
                        
    
                    
    • 
                    
  • TCP (Transmission Control Protocol)
                        
      
                            
    • Garante que os dados cheguem completos e na ordem correta
      • 
                            
    • Usado "por baixo" do HTTP
      • 
                        
    
                    
    • 
                    
  • IP (Internet Protocol)
                        
      
                            
    • Identifica quem envia e quem recebe
      • 
                            
    • Exemplo: IP do cliente, IP do servidor
      • 
                        
    
                    
    • 
                    
  • WebSocket
                        
      
                            
    • Comunicação em tempo real
      • 
                            
    • Usado em: Chats, jogos online, notificações instantâneas

            21 · COMO O NAVEGADOR INTERPRETA O HTML
            
Do texto à página na tela.


            

                
O arquivo HTML é apenas texto. Entre receber esse texto e mostrar pixels na tela, o navegador passa por um processo chamado Critical Rendering Path (caminho crítico de renderização).


                
🏭 As etapas (clique para ver cada uma)

                

                    
                    
                    
                    
                    
                    
                    
                    
                

                


                
📜 Resumo das etapas

                

                    
EtapaO que acontece

                    
                        
1. Bytes → caracteresO navegador recebe bytes e os converte em texto usando o charset (UTF-8)

                        
2. TokenizaçãoO texto é quebrado em tokens: "tag de abertura p", "texto Olá", "tag de fechamento p"

                        
3. DOMOs tokens viram nós organizados em árvore: o Document Object Model

                        
4. CSSOMO CSS também vira uma árvore de regras de estilo

                        
5. Render TreeDOM + CSSOM: só o que será visível (sem head, display:none etc.)

                        
6. Layout (reflow)Calcula posição e tamanho exato de cada caixa na tela

                        
7. PaintDesenha textos, cores, bordas, imagens e sombras em camadas

                        
8. CompositeJunta as camadas na ordem certa e exibe na tela (geralmente com ajuda da GPU)

                    
                


                
🧠 O DOM não é o seu código-fonte

                
O DOM é a representação viva da página na memória. O JavaScript lê e altera o DOM, não o arquivo. Por isso:

                
    
                    
  • Exibir código-fonte (Ctrl+U) mostra o HTML original que veio do servidor
    • 
                    
  • Inspecionar elemento (F12) mostra o DOM atual, já corrigido e modificado pelo JavaScript
    • 
                


                
⏸️ Scripts bloqueiam a leitura do HTML

                
Quando o parser encontra um <script> comum, ele para, baixa e executa o script, e só depois continua. Use defer ou async:

                

                    
FormaDownloadExecuçãoUso ideal

                    
                        
<script src>Bloqueia o HTMLImediata, bloqueandoEvite no head

                        
<script defer>Em paraleloApós o HTML terminar, na ordem✅ Scripts do seu site

                        
<script async>Em paraleloAssim que baixar, fora de ordemAnalytics, anúncios

                        
<script type="module">Em paraleloComo defer por padrãoJavaScript moderno com import

                    
                


                
🩹 O navegador perdoa (quase) tudo

                
Diferente de uma linguagem de programação, HTML inválido não gera erro. A especificação HTML5 define exatamente como o navegador deve consertar o código quebrado, para que todos os navegadores cheguem ao mesmo resultado.

                

                    
                    
                    
Como o navegador corrigiu (DOM final):

                    

                

                

                    ⚠️ Por isso valide seu HTML: o conserto automático pode gerar uma estrutura diferente da que você imaginou (repare como o <div> fecha o <p>!). Use o W3C Validator.
                


                
🦖 Quirks Mode: o que acontece sem o DOCTYPE

                
Sem <!DOCTYPE html>, o navegador entra no modo de compatibilidade (quirks mode) e imita bugs de navegadores dos anos 90, para não quebrar sites antigos. Tamanhos de caixas, tabelas e alinhamentos podem mudar.

                
// Descubra o modo no console do navegador:
document.compatMode
// "CSS1Compat"  → modo padrão ✅
// "BackCompat"  → quirks mode ⚠️

                    ✨ Motores de renderização: quem faz todo esse trabalho é o engine: Blink (Chrome, Edge, Opera, Brave), Gecko (Firefox) e WebKit (Safari e, na maioria dos países, todos os navegadores do iPhone).

            27 · CURIOSIDADES E DICAS
            
Fatos interessantes sobre HTML.

            
            

                

                    💡 Dica 1: HTML não é uma linguagem de programação, é uma linguagem de marcação. Ela define a estrutura do conteúdo, não a lógica.
                


                

                    📌 Dica 2: Você precisa de HTML + CSS + JavaScript para criar uma web moderna. HTML é a estrutura, CSS é a aparência, e JavaScript é o comportamento.
                


                

                    🎯 Dica 3: Todo site que você acessa começa com HTML. Mesmo aplicações web complexas (Google, Facebook, Netflix) têm HTML como base.
                


                

                    ⚠️ Dica 4: Nunca coloque senhas ou informações sensíveis no HTML. Todo código HTML pode ser visto pelo usuário no navegador (inspecionar elemento).
                


                

                    📌 Dica 5: O HTML evolui constantemente. Novas tags e funcionalidades são adicionadas regularmente. Acompanhe a documentação oficial!
                


                

                    💡 Dica 6: O primeiro site da história ainda está no ar: info.cern.ch. Inspecione o código: HTML de 1991 ainda funciona nos navegadores atuais!
                


                

                    📌 Dica 7: Não existe mais "HTML6". Desde 2019 o HTML é um Living Standard (padrão vivo) mantido pelo WHATWG, atualizado continuamente, sem números de versão.
                


                

                    🎯 Dica 8: O HTML tem cerca de 110 elementos, mas a maioria dos sites usa menos de 30. Domine os principais e consulte o MDN para o resto.
                


                

                    💡 Dica 9: "Hipertexto" é texto com links para outros textos. O "H" de HTML e de HTTP (HyperText Transfer Protocol) vem da mesma ideia: a web é uma rede de documentos ligados.
                


                

                    📌 Dica 10: E-mails em HTML ainda usam técnicas dos anos 2000 (tabelas para layout e estilos inline), porque os clientes de e-mail suportam bem menos recursos que os navegadores.

            29 · ATIVIDADE PRÁTICA
            
Hora de colocar a mão na massa!

            
            

                

                    🎯 Tarefa: Crie seu primeiro arquivo HTML!
                


                
📋 Instruções:

                
    
                    
  1. Abra um editor de texto (VS Code, Sublime, Notepad++, etc.)
    2. 
                    
  2. Crie um arquivo chamado meu-primeiro-site.html
    3. 
                    
  3. Copie e cole o código abaixo:
                        
    <!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro Site</title>
</head>
<body>
    <h1>Olá, Mundo! 👋</h1>
    <p>Esse é meu primeiro site em HTML!</p>
    <p>Estou começando minha jornada no desenvolvimento web.</p>
</body>
</html>
    
                    
    4. 
                    
  4. Salve o arquivo e abra-o no navegador
    5. 
                    
  5. Parabéns! Você criou seu primeiro site em HTML! 🎉
    6.

  • Adicione um parágrafo com seu nome e uma breve descrição

  • Adicione um link para sua rede social favorita

  • Mude o título da página (aquele que aparece na aba do navegador)
    • 
                    
  • Adicione uma imagem (use um link de imagem online)
    • 
                    
  • Use headings diferentes (<h2>, <h3>, etc.)
    •
