Aprenda como incluir imagens em suas páginas HTML, otimizá-las para melhor performance, usar formatos modernos e garantir acessibilidade.

01 · O QUE SÃO IMAGENS NA WEB

Imagens: a linguagem visual da web

Imagens são arquivos digitais que enriquecem a experiência do usuário. Transmitem informações rapidamente e melhoram a retenção de conteúdo.

Por que usar imagens?

  • Comunicação visual: transmitem informações em milissegundos
  • Engajamento: conteúdo visual atrai e mantém atenção
  • Memória: pessoas lembram 65% de imagens vs 10% de texto
  • SEO: imagens otimizadas ajudam no posicionamento
💡 Dica: Uma imagem bem otimizada pode fazer diferença entre um site rápido e um lento!
02 · A TAG <img>

A tag mais importante para imagens

A tag <img> é a forma padrão de inserir imagens. É uma tag void (vazia).

Sintaxe básica

<img src="caminho/imagem.jpg" alt="Descrição">

Atributos essenciais

AtributoDescrição
srcURL da imagem (obrigatório)
altTexto alternativo (obrigatório)
widthLargura em pixels
heightAltura em pixels
loadingLazy loading (lazy/eager)
⚠️ Importante: A tag <img> é autofechável. Não feche com </img>!
03 · ATRIBUTO src

Especificando o caminho da imagem

O atributo src define o caminho ou URL da imagem. É obrigatório.

Tipos de caminho

Caminho Relativo

<img src="images/foto.jpg" alt="Foto">

Caminho Absoluto

<img src="/images/foto.jpg" alt="Foto">

URL Completa

<img src="https://ex.com/img.jpg" alt="Img">
04 · ATRIBUTO alt

Tornando imagens acessíveis

O atributo alt fornece descrição textual. Essencial para acessibilidade.

Como escrever um bom alt?

❌ Errado

<img src="gato.jpg" alt="gato">
<img src="foto.jpg" alt="imagem">

✅ Correto

<img src="gato.jpg" alt="Gato laranja dormindo">
<img src="foto.jpg" alt="Equipe reunida">
05 · DIMENSÕES: width E height

Controlando o tamanho da imagem

Use width e height para evitar layout shift.

<img src="foto.jpg" alt="Foto" width="300" height="200">
<img src="foto.jpg" alt="Foto" width="300" height="auto">

Para responsividade

img {
    max-width: 100%;
    height: auto;
}
06 · TAG <figure>

Agrupando imagens com contexto

A tag <figure> agrupa conteúdo visual com legenda.

<figure>
    <img src="grafico.png" alt="Gráfico Q1">
    <figcaption>Gráfico de vendas do primeiro trimestre</figcaption>
</figure>
07 · TAG <picture>

Imagens adaptadas a cada dispositivo

A tag <picture> serve diferentes imagens por tamanho de tela.

<picture>
    <source media="(max-width: 600px)" srcset="img-pequena.jpg">
    <img src="img-grande.jpg" alt="Imagem responsiva">
</picture>

09 · LAZY LOADING

Carregando imagens sob demanda

Lazy loading adia o carregamento até a imagem ficar visível.

<img src="imagem.jpg" alt="Imagem" loading="lazy">
10 · OTIMIZAÇÃO DE PERFORMANCE

Tornando imagens leves e rápidas

Checklist

  • ✅ Largura e altura definidas
  • ✅ Alt descritivo
  • ✅ Formato correto (WebP)
  • ✅ Comprimida
  • ✅ Lazy loading
11 · BOAS PRÁTICAS

Checklist essencial para imagens

Sempre faça

  • ✅ Use atributo alt SEMPRE
  • ✅ Defina width e height
  • ✅ Optimize tamanho antes de enviar

Nunca faça

  • ❌ Não use alt="" para imagens importantes
  • ❌ Não carregue imagens maiores que o container
  • ❌ Não ignore performance
12 · EXEMPLOS PRÁTICOS

Código pronto para usar

Exemplo 1: Responsiva

<img src="gato.jpg" alt="Gato laranja" width="600" height="400" loading="lazy" style="max-width: 100%;">

Exemplo 2: Picture com WebP

<picture>
    <source srcset="foto.webp" type="image/webp">
    <img src="foto.jpg" alt="Foto" loading="lazy">
</picture>
